# Birth Care Accessibility Dashboard – Graubünden, Switzerland

This repository contains the source code for a dashboard developed as part of a Bachelor's thesis. The project analyzes the travel-time accessibility of obstetric care facilities in the canton of **Graubünden**, Switzerland, using **GIS-based methods** and visualizes the results in an interactive dashboard built with **Plotly Dash**.

## Project Overview

The goal of the dashboard is to explore how the potential closure of one or more obstetric care facilities would impact accessibility for the population in Graubünden. The dashboard allows users to:

- View current travel-time accessibility to obstetric services by municipality
- Simulate different closure scenarios of specific hospitals
- Compare travel times before and after facility closures

## Getting Started
1. Clone the Repository
2. Install dependencies
3. Run the App: dashboard.py
